# MIS205 课程项目说明（脱敏版）

## 项目概述

本项目由三名成员共同完成，目标是设计一个供高校学生与活动组织者使用的校园活动报名系统。团队共同参与需求梳理、关系数据库设计和前端原型开发，并同意将脱敏版本用于公开展示。

## 业务流程

1. 校园人员使用姓名、学号或工号、校园邮箱完成身份匹配。
2. 通过验证的用户注册或登录系统。
3. 用户浏览并按照学院、书院、社团和活动类型筛选活动。
4. 用户报名或取消报名，系统显示当前人数与容量。
5. 活动组织者创建、编辑和删除自己发布的活动。

## 数据模型

- `school_personnel`：校园人员白名单，仅用于注册验证。
- `profiles`：与 Supabase Auth 用户一一对应的公开资料。
- `events`：活动信息及组织者关系。
- `registrations`：用户和活动之间的多对多关联记录。

## 当前实现边界

课程原型以原生 HTML、CSS 和 JavaScript 实现交互，数据保存在浏览器内存中。仓库中的 Supabase 数据模型属于设计方案，不能将原型描述为已经完成后端集成。

本作品集仓库将在此基础上继续实现真实的 Supabase Auth、数据库持久化、RLS 权限、测试和在线部署。
